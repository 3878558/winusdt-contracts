## 6. Банкролл LP-пула (feeShare = 0, maxBet = max(0.5, min(10, fb/300)))

2000 прогонов × 365 дней × 1000 спинов/день (спрос: 60% × 0.5 / 30% × 1 / 10% × 5, обрезка по maxBet; admission fb ≥ 100×bet; ruin = fb < 50).

| Старт | P(ruin)/год | 95% CI | min fb / старт (p50 / p05) | дней impaired / turbo |
|---|---|---|---|---|
| 50 | 92.300% | [91.049%…93.389%] | 99% / 87% | 0.3% / 7.2% |
| 100 | 9.100% | [7.917%…10.440%] | 88% / 48% | 0.5% / 84.6% |
| 300 | 0.000% | [0.000%…0.192%] | 94% / 69% | 0.0% / 95.0% |
| 1500 | 0.000% | [0.000%…0.192%] | 96% / 78% | 0.0% / 100.0% |
| 3000 | 0.000% | [0.000%…0.192%] | 98% / 88% | 0.0% / 100.0% |

**Трактовка ruin:** при admission (fb ≥ 100×bet) insolvency (fb < 0) механически НЕВОЗМОЖНА — выплату нельзя принять, не покрыв её худший исход. Ruin здесь = **операционная остановка**: fb < 50 → контракт отвергает даже minBet (absorbing: нет спинов → нет edge → нужен доп. депозит). Это ЧЕСТНЕЕ наивной диффузионной оценки §3: машина на 50 останавливается почти наверняка, на 100 — риск значим, 300 — безопасно.

Определения: **impaired** — день с maxBet, флоренным на 0.5 (fb < 150); **turbo** — день с доступным Turbo ×10 при bet 1 (fb ≥ 990). Отказы admission на живом банкролле практически нулевые.
